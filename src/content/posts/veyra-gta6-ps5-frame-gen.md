## 先说结论

1. **PS5 这边什么都不用改。** Veyra 不注入游戏、不打补丁，它只是"接管画面"。
2. **必须有采集卡。** 它决定了你这条路走不走得通，而不是显卡。
3. **补出来的帧不是免费的性能。** 延迟会变差，画质靠显卡硬扛，30 帧的底子依旧是 30 帧的底子。

## 为什么绕不开采集卡

PS5 是封闭平台。PC 上那种往进程里注入、劫持渲染管线做帧生成的玩法，在主机上不存在。

所以只能在**画面之外**动手：把 PS5 输出的画面当成一路视频信号，先让 PC 能"看到"它，再对这路视频做超分和补帧，最后送去显示。

Veyra（全名 Veyra-NRVideo，开源项目，见 [GitHub](https://github.com/Likely7/Veyra-NRVideo)）本质就是一个 Windows 上的实时视频增强器：它可以读本地视频、图片，也可以直接读**采集卡信号**，把 AI 超分辨率、画质增强和帧生成叠在输入上。

这就是为什么标题里要强调"采集卡"——它是把主机画面送进 Veyra 的唯一无损通道。没有它，你只剩 PS5 的 Remote Play 串流：码率被压缩、画面糊、延迟更高，效果和采集卡完全不是一回事。

## 链路长什么样

```text
PS5 ──HDMI 2.1──> 采集卡 ──USB 3.2──> PC（Veyra：超分 + 降噪 + 补帧）──HDMI/DP──> 显示器/电视
```

PS5 输出的 30 帧（GTA6 在主机上的目标帧率）进入 PC，Veyra 按 2x / 3x / 4x 插帧，输出 60 / 90 / 120 帧。

**注意**：你眼睛看到的是显示器上的 120 帧，但游戏逻辑、输入响应仍然是 PS5 的 30 帧。这一点必须先接受，否则后面会觉得"补了帧怎么还是那个手感"。

## 硬件清单

| 部件 | 要求 | 说明 |
| --- | --- | --- |
| 主机 | PS5 / PS5 Pro | 游戏本身不改动 |
| 线材 | HDMI 2.1 | 4K120 必须 2.1，2.0 的线只能 4K60 |
| 采集卡 | 4K60 起步，越高越好 | 这是整条链路的瓶颈。4K60 的卡意味着你最多 4K60 进 PC，再补帧 |
| 显卡 | 高端 NVIDIA / AMD | 官方宣传支持 DLSS5 类增强，NVIDIA RTX 40 / 50 系是主要目标；30 → 120 帧的活儿对显卡压力非常大 |
| CPU | 能稳定解码 4K 视频 | 别让软解抢走 GPU 的算力 |
| 显示器 | 120Hz 以上 + 支持你打算用的分辨率 | 输出端跑不动，前面全白搭 |

> 关于"至少需要 RTX 5070 / RX 9070XT"这类说法，来自媒体根据宣传做的**推测**，不是开发者公布的配置表。真机能不能到 120 帧，取决于你的采集卡上限、分辨率和补帧倍率。

## 设置步骤

### 1. 先把采集卡跑通

PS5 的 HDMI 进采集卡，采集卡的 USB 接 PC。先不要开 Veyra，直接用系统的相机/采集软件确认能出画面。

黑屏九成是 **HDCP**：部分游戏/播放器会打开内容保护，采集卡读不到。PS5 设置里可以把 HDCP 关掉（设置 → 系统 → HDMI），关了之后采集卡才有画面。

### 2. PS5 输出设置

- 分辨率：按采集卡能力选 2160p 或 1080p，别让它两边协商失败
- 刷新率：120Hz 输出打开
- HDR：先关。多数采集卡不支持 HDR 直通，开了会发灰或黑屏，等链路稳定后再试
- VRR：采集卡不支持就关掉

### 3. Veyra 里选输入源

打开 Veyra，把输入源切到采集卡设备，分辨率/帧率自己选，输出分辨率会跟你的显示器或电脑走。

![Veyra 主界面：输入源卡片里选「采集卡」](/assets/images/veyra/01-home.png "图 1　Veyra 主界面：输入源选「采集卡」")

![采集卡设置：设备选自己的采集卡，分辨率 / 帧率自己选](/assets/images/veyra/02-capture-card.png "图 2　采集卡设置：设备选你自己的（比如博主的 Elgato 4K X），输出分辨率跟显示器或电脑走，再连接并开始")

**第一次用，把所有增强效果全部关掉。** 先确认这一路信号在 Veyra 里是稳定、不撕裂、不闪的。开发者自己也是这么建议的：从零效果开始，再一项一项加。

![连接采集卡后：信号已识别，增强全部关闭，先确认基础画面](/assets/images/veyra/03-connected.png "图 3　连接采集卡后：2160p30 信号已识别，增强全部关闭，先确认基础画面稳定")

### 4. 逐项打开增强

按这个顺序加，每加一项都观察 GPU 占用和温度：

1. **超分辨率**：把采集卡进来的 1080p 拉到 1440p / 4K。这一项吃显卡最狠
2. **降噪 / 画质增强**：抵消采集和压缩带来的噪点
3. **帧生成**：最后开。倍率从 2x 开始，30 → 60 能稳住再往 3x、4x 试

![补帧设置：方式选 DLSS 帧生成，运动来源选光流，倍率从 2X 起步](/assets/images/veyra/04-framegen-dlss.png "图 4　补帧设置：补帧方式选 DLSS 帧生成，运动来源选光流，倍率从 2X 起步")

任何一项开下去 GPU 直接 99% 并且掉帧，就退回来降一档。别指望四项全开还能 4K120。

![补帧方式下拉：RTX 30 / 40 / 50 系显卡选 NVIDIA VFG（顶级补帧质量）](/assets/images/veyra/05-framegen-vfg.png "图 5　RTX 30 / 40 / 50 系显卡补帧方式选 NVIDIA VFG（顶级补帧质量）")

### 5. 校准延迟

补帧是插值，它只会让**显示**更顺，不会让输入更快。整条链路的延迟大致是三块叠加：

- PS5 输出延迟
- 采集卡处理 + USB 传输：几十毫秒量级，卡越便宜越明显
- Veyra 的增强 + 补帧：多缓存 1~2 帧

120 帧下 1 帧只有 8.3ms，所以补帧本身的代价不大，**真正的大头是采集卡**。如果手感明显拖沓，优先怀疑采集卡和它的 USB 带宽。

## 适合什么、不适合什么

| 场景 | 合适度 | 原因 |
| --- | --- | --- |
| 单人剧情、开车看风景 | 合适 | 延迟不敏感，画面顺滑收益最大 |
| 录屏 / 直播 / 剪辑素材 | 合适 | 直接拿到高帧素材 |
| GTA6 线上 PvP | 不建议 | 插值帧不携带新的输入信息，对枪吃亏 |
| 需要精准判定的玩法 | 不建议 | 同上 |

## 常见问题

**采集卡黑屏 / 提示无信号**
先关 HDCP，再换一根 HDMI 2.1 线，最后检查是不是插在了 USB 2.0 口上。

**画面撕裂**
输出端刷新率和 Veyra 输出的帧率没对齐。把显示器刷新率设成补帧后的目标值，或者开垂直同步试。

**帧数上不去**
按顺序排查：采集卡上限 → 补帧倍率 → 超分分辨率 → 显卡本身。四项里降任何一项都会有明显改善。

**声音不同步**
采集卡的音频延迟和视频延迟不一致，在 Veyra 里微调音频偏移。

**颜色发灰**
HDR 没配对。链路里只要有一个环节不支持 HDR，就全程关掉 HDR。

## 必须说清楚的三件事

1. **性能数据来自开发者宣传。** "PS5 的 GTA6 跑到 120 帧以上"是 Veyra 方面的说法，目前没有独立测试，索尼和 Rockstar 也都没有回应。
2. **补帧 ≠ 提性能。** 游戏依然按 30 帧在跑，你只是让画面看起来更连续。手感和画质上限都在 PS5 那边。
3. **成本不低。** 一块支持 4K 的采集卡加一张高端显卡，价格可能已经超过 PS5 Pro 本身。先想清楚是为了顺滑，还是为了数字。
